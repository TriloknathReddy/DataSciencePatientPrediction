# Diabetic Retinopathy Prediction App

This project contains a Streamlit dashboard for diabetic retinopathy risk screening using patient vital signs.

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deployment notes

- This app uses a single entry point: app.py
- The dataset file dataset.csv is included for local and cloud deployment
- Streamlit Community Cloud will install dependencies from requirements.txt automatically
